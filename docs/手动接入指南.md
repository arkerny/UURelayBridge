# 手动接入指南（Clash Verge Rev）

UURelayBridge **不写 Clash 的任何文件**：它只把生成的脚本给你，你自己粘贴。
需要"按域名分片绕过 SNI 阻断"的，看文末的 Host 模式。

---

## 1. 先确认两件事

| 检查 | 怎么看 |
|---|---|
| 策略组叫什么 | Clash Verge Rev → 配置 → 打开订阅 YAML → `proxy-groups:` 下的 `- name: xxx`。规则里的名字必须**完全一致**（含 emoji 和空格）。 |
| 现在开关是 ON 吗 | 主界面右上角开关；ON = 脚本会注入规则，OFF = 不注入。 |

## 2. 定义规则

1. 「规则」→「新建规则」：
   - **名称**：随便，如 `UU 远程控制面`
   - **匹配域名**：`nrd.nie.163.com`（后缀匹配，覆盖自身与所有子域）
   - **匹配 IP / CIDR**：可选，如 `10.0.0.0/8`
   - **动作**：代理到策略组 / 直连 / 拒绝
2. 顺序 = 注入顺序；点 **保存规则**（只写 `project.json`，不生成文件）。

## 3. 复制脚本

1. 顶部开关切到 **ON**（只更新生成内容）。
2. 「概览 → 生成内容预览」里就是完整脚本，点 **复制**。
   - 想留文件副本再点 **导出到文件**（写到 `%APPDATA%\UURelayBridge\output\clash-verge-rev\`）。

## 4. 粘贴进 Clash Verge Rev

1. 订阅页 → 右键当前配置 → **编辑扩展脚本**（不同版本可能叫「编辑 Script」）。
2. 全选替换为刚才复制的内容，保存。
3. 回到订阅页 → 右键 → **重新加载**（或点卡片上的刷新）。

规则会出现在最前面；用「连接」页发一次请求即可验证走向。

## 5. 停用

开关切 **OFF** → 重新复制 → 重新粘贴 → 重载。OFF 版本会移除上次注入的那些完全相同规则，
其余规则原样保留。

> UURelayBridge 不会通知 Clash 刷新 —— 生效时机由你决定，这也是"零侵入"的代价。

## 6. Host 模式（另一种用法）

如果问题不是"该走代理"，而是"带这个 SNI 的连接被链路上的设备直接掐断"，用 Host 模式：

1. 「Host 模式」页：域名填 `nrd.nie.163.com`，端口 443，分片方式 TLS Record，4 段。
2. 点 **启动转发**（本机开始监听）。
3. 点 **写入 Hosts** → 弹 UAC，同意。只会加一段带标记的记录。
4. 正常使用目标应用。日志会显示 `域名 → 真实IP（TLS Record 分片 4 段 …）`。
5. 不用时：**停止**转发 + **移除 Hosts**（或保持程序运行）。

⚠ 写完 hosts 后，这些域名只有在「程序在跑 + 转发已启动」时才可用。
⚠ 分片只对"按明文 SNI 简单匹配"的设备有效；DNS 污染 / IP 封锁 / QUIC 封锁 / 主动探测都解决不了。

## 7. 常见问题

**规则写了不生效？**
- 策略组名对不上：Clash 控制台里会有 `[UURelayBridge] 这些策略组在你的配置里不存在: xxx`。
- 忘了重载脚本。

**Host 模式启动失败？**
- 443 被占用（可能上次没退干净）→ 换端口或先停旧实例。
- macOS 绑 443 需要 root。

**写入 Hosts 失败？**
- 取消了 UAC；或目标文件被安全软件锁住。重试一次，或手动把日志里提示的错误发出来。
