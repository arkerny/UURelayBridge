# 手动接入指南（Clash Verge Rev）

RelayBridge **不会**自动把配置塞进 Clash Verge，也不修改它的订阅、配置文件或数据库。
下面是完整的"人肉"接入流程，一次配置、之后只需替换脚本内容。

---

## 0. 先确认两件事

| 检查 | 怎么看 |
|---|---|
| 你的策略组叫什么 | Clash Verge Rev → 「配置」→ 打开当前订阅的 YAML，找 `proxy-groups:` 下的 `- name: xxx`。规则里的策略组名必须**完全一致**（包括 emoji 和空格）。 |
| 目标文件在哪 | RelayBridge 主界面「概览 → 输出文件」会显示完整路径，默认：<br>Windows `%APPDATA%\RelayBridge\output\clash-verge-rev\relaybridge.js`<br>macOS `~/Library/Application Support/RelayBridge/output/clash-verge-rev/relaybridge.js` |

---

## 1. 在 RelayBridge 里定义规则

1. 打开 RelayBridge（托盘图标 / 菜单栏图标 → 打开主界面）。
2. 「规则」→「新建规则」：
   - **名称**：随便写，例如 `UU 远程控制面`
   - **匹配域名**：每行一个。填 `nrd.nie.163.com` 就覆盖它自己和所有子域；
     也可以写 `*.example.com`，效果相同。
   - **匹配 IP / CIDR**：可选，例如 `10.0.0.0/8`（自动补成 `IP-CIDR,...,no-resolve`）。
   - **动作**：`代理到指定策略组` / `直连` / `拒绝`。
3. 需要的话再建几条，注意**表格从上到下的顺序就是注入顺序**。
4. 点右上角 **保存规则**，在确认框里点「确认」——此时才写 `project.json` 并生成脚本。

> 规则改动先进入草稿，关闭程序不会丢失已保存内容；未保存的改动会显示"有未保存修改"。

## 2. 打开开关（ON）

顶部开关切到 **ON** → 确认框 → 生成 `relaybridge.js`。

- 生成的是**启用版本**：`var RB_ENABLED = true;`，规则会被插到最前面。
- 同时生成 `manifest.json`（记录了 sha256 和时间），旧版本自动进 `backups/`。
- 「概览 → 生成内容预览」可以直接看到将要粘贴的内容，点「复制」即可。

## 3. 粘贴进 Clash Verge Rev

1. Clash Verge Rev → 「订阅」页 → 找到你正在用的配置。
2. 右键该配置 → **编辑扩展脚本**（不同版本可能叫「编辑 Script」/「扩展脚本」）。
3. 把 `relaybridge.js` 的**全部内容**粘贴进去，保存。
4. 回到订阅页，右键配置 → **重新加载/刷新**（或点配置卡片上的刷新按钮）。

此时 Clash 的规则列表最前面会出现你定义的那几条；用「连接」页发起一次请求即可验证走向。

## 4. 停用（OFF）

1. RelayBridge 顶部开关切到 **OFF** → 确认 → 生成 `var RB_ENABLED = false;` 的版本。
2. 重新按第 3 步粘贴、保存、重载。

OFF 版本会**移除**它上次注入的那些完全相同的规则，其余规则原样保留。

> ⚠️ RelayBridge 不通知 Clash 刷新：不重新粘贴/重载，Clash 里仍会保持旧规则。
> 这正是"零侵入"的代价，也意味着你始终掌控生效时机。

## 5. 常见问题

**Q：规则写了但不生效？**
- 策略组名对不上 → 打开 Clash Verge Rev 的日志/控制台，脚本会用 `console.warn` 提示
  `[RelayBridge] 这些策略组在你的配置里不存在: xxx`。
- 规则被 `MATCH` 之类终结规则抢先 → RelayBridge 永远插在**最前面**，正常不会。
- 没有重载脚本 → 重载后再试。

**Q：能自动更新吗？**
不能，也不打算做。RelayBridge 只负责生成文件。

**Q：会不会改我的订阅？**
不会。它只写自己数据目录里的 `relaybridge.js` / `manifest.json` / `backups/*`。
你可以用编辑器打开 Clash Verge 的配置目录对比。

**Q：想让某条规则临时失效？**
「规则」页取消该条勾选 → 保存规则 → 重新粘贴脚本。或者直接切 OFF。

**Q：备份在哪、会不会无限增长？**
`backups/relaybridge-<时间戳>.js`，默认保留最近 20 份（设置里可改 1–200）。
只清理自己这个前缀的文件，你放进该目录的其他文件不会被删。
