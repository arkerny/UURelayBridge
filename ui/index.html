接入方式（手动）

  1. 点上面的开关切到 ON，RelayBridge 生成 relaybridge.js。
  2. 打开 Clash Verge Rev → 订阅 → 选中配置 → 右键「编辑扩展脚本」。
  3. 把生成的文件内容整段粘贴进去并保存，然后重载配置。

本程序不写入 Clash Verge 的任何文件、不导入、不改订阅、不调用 Controller API。 OFF 只会让脚本停止注入，已加载的规则需要你在 Clash Verge 里重新加载脚本才会消失。

它怎么工作

  1. 本机监听 127.0.0.1:端口，只接受 TLS。
  2. 读 ClientHello，取出 SNI，用 DNS 查真实 IP（不会绕回 hosts 里的 127.0.0.1）。
  3. 按域名决定是否把这条记录拆成多段再转发，之后双向透传。
  4. hosts 把域名指到 127.0.0.1，系统才把流量送进来 —— 这一步需要管理员。
